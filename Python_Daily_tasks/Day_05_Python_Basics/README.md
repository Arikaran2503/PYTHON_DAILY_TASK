# 🐍 Day 05 - Python Lists & List Methods

This folder contains my **Day 05 Python practice programs**. In this session, I learned about Python lists, indexing, slicing, built-in list methods, and different list operations.

## 📚 Topics Covered

- List Basics
- List Indexing
- List Slicing
- List Methods
- List Operations
- Adding and Removing Elements
- Updating List Elements

## 📂 Programs

### 1. List Basics
**File:** `list_basics.py`

- Creating and storing lists.
- Accessing list elements using indexing.
- Finding the length of a list using `len()`.
- Working with different data types in a list.

### 2. List Indexing & Slicing
**File:** `list_indexing_slicing.py`

- Accessing elements using positive and negative indexing.
- Extracting specific elements using slicing.
- Reversing a list using slicing.
- Practicing different slicing techniques.

### 3. List Methods
**File:** `list_methods.py`

Practiced commonly used Python list methods:

- `append()`
- `insert()`
- `remove()`
- `pop()`
- `sort()`
- `reverse()`
- `count()`
- `index()`

### 4. List Operations
**File:** `list_operations.py`

- List concatenation.
- List repetition.
- Membership operators (`in`, `not in`).
- Updating list elements.
- Adding elements to a list.
- Deleting elements using `del`.
