# 🐍 Day 7 – Python Dictionaries & Dictionary Methods

Welcome to **Day 7 of my Python Daily Learning Journey!**

Today, I practiced Python Dictionaries and learned how to store, access, update, delete, and iterate through key-value pairs using different dictionary methods.

## 📚 Topics Covered

- Dictionary Basics
- Accessing Dictionary Values
- Dictionary Methods
- Dictionary Operations
- Looping Through Dictionaries

## 💻 Programs

### 1. `dictionary_basics.py`
- Creating dictionaries using key-value pairs.
- Storing student details in a dictionary.
- Displaying dictionary data.

### 2. `dictionary_access.py`
- Accessing dictionary values using keys.
- Using the `get()` method.
- Displaying dictionary keys and values using `keys()` and `values()`.

### 3. `dictionary_methods.py`
- Adding new items to a dictionary.
- Updating dictionary values using `update()`.
- Removing items using `pop()`.
- Displaying dictionary items using `items()`.

### 4. `dictionary_operations.py`
- Adding and updating dictionary items.
- Checking whether a key exists using `in`.
- Deleting dictionary items using `del`.
- Finding the number of items using `len()`.

### 5. `dictionary_loop.py`
- Iterating through dictionary keys.
- Accessing values using keys.
- Using `items()` to loop through key-value pairs.
