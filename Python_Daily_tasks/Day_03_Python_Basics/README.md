# 🐍 Day 03 - Python Loops

This folder contains my **Day 03 Python practice programs**. In this session, I learned about loops and loop control statements in Python.

## 📚 Topics Covered

- For Loop
- While Loop
- Nested Loops
- Break Statement
- Continue Statement

## 📂 Programs

### 1. For Loop
**File:** `for_loop.py`

- Used for loop to execute a block of code repeatedly.
- Practiced the `range()` function.
- Printed numbers from 1 to 10.

### 2. While Loop
**File:** `while_loop.py`

- Used while loop to execute code based on a condition.
- Practiced incrementing values.
- Printed numbers from 1 to 10.

### 3. Nested Loop
**File:** `nested_loop.py`

- Practiced using one loop inside another loop.
- Printed number combinations using nested loops.

### 4. Break and Continue
**File:** `break_continue.py`

- `break` - Stops the loop completely.
- `continue` - Skips the current iteration and moves to the next iteration.
