# 🐍 Day 06 - Python Tuples & Sets

This folder contains my **Day 06 Python practice programs**. In this session, I learned about Python tuples, sets, their built-in methods, and different set operations.

## 📚 Topics Covered

- Tuple Basics
- Tuple Indexing
- Tuple Methods
- Set Basics
- Set Methods
- Set Operations
- Removing Duplicate Elements
- Union, Intersection and Difference

## 📂 Programs

### 1. Tuple Basics
**File:** `tuple_basics.py`

- Creating and storing tuples.
- Accessing tuple elements using indexing.
- Understanding positive and negative indexing.
- Finding tuple length using `len()`.
- Working with different data types in tuples.

### 2. Tuple Methods
**File:** `tuple_methods.py`

Practiced commonly used tuple functions and methods:

- `count()`
- `index()`
- `len()`
- `max()`
- `min()`
- `sum()`
- Converting tuples into lists using `list()`.

### 3. Set Basics
**File:** `set_basics.py`

- Creating and storing sets.
- Understanding unordered collections.
- Removing duplicate values automatically.
- Adding elements using `add()`.
- Checking elements using membership operators.
- Finding set length using `len()`.

### 4. Set Methods
**File:** `set_methods.py`

Practiced commonly used Python set methods:

- `add()`
- `update()`
- `remove()`
- `discard()`
- `pop()`
- `copy()`
- `clear()`

### 5. Set Operations
**File:** `set_operations.py`

Practiced mathematical set operations:

- Union
- Intersection
- Difference
- Symmetric Difference
- Subset
- Superset
