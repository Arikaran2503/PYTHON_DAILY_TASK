# 🐍 Day 04 - Python Strings & String Methods

This folder contains my **Day 04 Python practice programs**. In this session, I learned about strings, string indexing, slicing, and different built-in string methods in Python.

## 📚 Topics Covered

- String Basics
- String Indexing
- String Slicing
- String Methods
- String Operations
- String Concatenation
- String Formatting (f-strings)

## 📂 Programs

### 1. String Basics
**File:** `string_basics.py`

- Creating and storing strings.
- Accessing individual characters using indexing.
- Finding string length using `len()`.
- Understanding positive and negative indexing.

### 2. String Slicing
**File:** `string_slicing.py`

- Extracting specific parts of a string.
- Using start and end indexes.
- Reversing a string using slicing.
- Practicing different slicing techniques.

### 3. String Methods
**File:** `string_methods.py`

Practiced commonly used string methods:

- `upper()`
- `lower()`
- `title()`
- `capitalize()`
- `strip()`
- `replace()`
- `find()`
- `count()`

### 4. String Operations
**File:** `string_operations.py`

- String concatenation.
- String repetition.
- Membership operators (`in`, `not in`).
- String formatting using f-strings.
